# 취향의 연결 지도

정적 HTML/CSS/JavaScript로 만든 반응형 개인 웹사이트입니다. 관심사 사이를 그래프로 연결하고, 사용자가 주제를 고르면 BFS(너비 우선 탐색) 순서로 가까운 연결을 하나씩 보여줍니다.

## 나답게 바꾸기

- `index.html`의 제목과 소개 문장을 본인 정보로 바꿔주세요. 연락처나 링크를 추가한다면 실제로 사용할 주소로 연결하세요.
- 지도 원의 이름과 짧은 설명은 각 `.node` 버튼 안의 문구를 수정하면 됩니다.
- `script.js`의 `topics` 객체에 각 관심사의 설명을 적고, `graph` 객체에서 연결 관계를 편집하세요. `graph`가 BFS에 쓰이는 인접 목록입니다.
- 지도 선은 `index.html`의 SVG 경로와 `script.js`의 `pathEdges` 순서로 그려져 있습니다. 연결을 바꾸면 선도 함께 조정해주세요.
- `style.css`에서 색상 변수와 글꼴, 레이아웃을 바꿀 수 있습니다.

## 열어보기

`index.html`을 브라우저에서 열면 됩니다. 별도 패키지 설치나 빌드 과정은 없습니다. Google Fonts는 인터넷 연결 시 적용되고, 연결이 없어도 시스템 글꼴로 표시됩니다.

공개 배포 후 로그인 없이 열리는 주소를 제출 파일 첫 줄에 적어주세요.
